# AI dialogue records

Place exported AI dialogue records here if any AI tools are used.

Suggested naming:

```text
YYYY-MM-DD_debugging_data_loader.md
YYYY-MM-DD_report_polishing.md
YYYY-MM-DD_gradcam_help.md
```

For each record, include:

- Date
- Tool name
- Purpose
- Important prompts and outputs
- How the group verified or modified the AI output

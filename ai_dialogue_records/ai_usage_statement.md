# AI Tool Usage Statement

During this project, AI tools were used to help scaffold and debug the deep learning workflow, including:

- Interpreting the assignment requirements and organizing the repository structure.
- Implementing PyTorch data loading, model training, validation, evaluation, Grad-CAM, and error analysis scripts.
- Suggesting README commands and a report template.
- Checking for syntax errors and improving reproducibility.

All AI-generated code and text should be reviewed, run, and understood by the group members. Reported metrics, confusion matrices, Grad-CAM outputs, and conclusions must come from real experiments on the prepared dataset, not from AI-generated guesses.
